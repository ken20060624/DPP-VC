Operator API Key 是什麼？

這是操作員的存取密鑰，和 Issuer 用來簽章 VC 的 Ed25519 私鑰不同。服務只保存它的 SHA-256 摘要；按「驗證授權」時會將 Key 當作 Bearer token 送至本機服務核對。

簽發與撤銷會再次檢查 Key；公開驗證 VC 不需要 Key，可直接前往第 3 頁貼上 JSON，再到第 4 頁驗證。Windows 啟動器會將 Key 複製到剪貼簿；Docker 使用者可依 README 的 docker compose exec 指令讀取。請勿把 Key 貼到聊天、截圖或提交到 Git。

重新整理頁面要再輸入。若 Key 外洩，需更換 Key 與服務端摘要；這不會更換 Issuer 簽章私鑰，也不會自動撤銷已簽憑證。
